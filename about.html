About Me

Mengenal lebih dekat perjalanan belajar saya di dunia pengembangan web dan teknologi jaringan.

Danendra Rosan

Halo! Nama saya Danendra Rosan, seorang pelajar Sekolah Menengah Kejuruan (SMK) di Indonesia yang sedang mendalami pengembangan website dan jaringan komputer.

Saat ini fokus utama saya adalah memahami cara kerja web dari dasar—mulai dari menulis struktur semantic HTML yang rapi, mengatur tata letak menggunakan CSS modern, hingga menambahkan interaksi sederhana dengan vanilla JavaScript.

Melalui proyek portofolio ini, saya berusaha menerapkan standar penulisan kode yang bersih dan mudah dipelihara serta konsisten di setiap halaman.

My Learning Journey

Tahapan belajar pengembangan web yang saya lalui secara bertahap.

  1. Tahap 01 — Fondasi Web

    Mengenal Struktur HTML5

    Mempelajari elemen dasar dokumen HTML, tag semantik seperti header, nav, main, section, serta penggunaan formulir dan tabel.

  2. Tahap 02 — Tata Letak & Gaya

    Memperdalam CSS3 & Responsivitas

    Berlatih menggunakan CSS variables, Flexbox, dan CSS Grid agar tampilan halaman tetap rapi di desktop, tablet, dan ponsel.

  3. Tahap 03 — Interaktivitas Dasar

    Dasar JavaScript & DOM

    Menggunakan JavaScript murni untuk membuat menu navigasi mobile, validasi formulir sederhana, dan tombol kembali ke atas.

  4. Tahap 04 — Eksplorasi Lanjutan

    Pengenalan PHP, MySQL & Networking

    Mulai mengenal cara kerja server lokal, basis data dasar, dan konsep jaringan komputer yang mendukung operasional aplikasi web.
